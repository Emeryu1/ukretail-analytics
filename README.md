# ukretail-analytics

![dbt CI](https://github.com/Emeryu1/ukretail-analytics/actions/workflows/ci.yml/badge.svg)

End-to-end analytics engineering pipeline: 1M+ rows of UK online retail transactions, loaded with Python into DuckDB, transformed through a tested, layered dbt project, visualised in Power BI.
